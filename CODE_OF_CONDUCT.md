# Code of conduct

This project adopts the Contributor Covenant, version 2.1, by reference. Its text is published at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and applies to every space of this project: the
repository, its issues and pull requests, and any channel the project opens.

To report a breach of it, use the same private route as for a security report, in SECURITY.md: the repository's
Security tab ("Report a vulnerability") or the project's security address named there. Reports are read by the
authors listed in AUTHORS and handled in confidence.

Enforcement follows the Covenant's guidelines, from a private warning to a permanent ban, decided by the authors.
